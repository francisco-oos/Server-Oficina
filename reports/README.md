# Reportes y evidencias de validación

Esta carpeta contiene resultados de pruebas, auditorías, revisiones
independientes, seguridad, PRE/POST y pendientes reales.

Los reportes son evidencia de una ejecución concreta; no sustituyen a la
documentación autoritativa de `../docs/`.

Regla para futuros agentes:
- documentación y decisiones -> `docs/`
- reportes de ejecución/auditoría -> `reports/`
- pruebas automatizadas -> `tests/`
- scripts auxiliares -> `scripts/`
- no dejar paquetes de relevo, parches temporales ni notas de trabajo en la raíz
