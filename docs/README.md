# Documentación de Server Oficina

La documentación técnica y funcional vive en esta carpeta.

## Punto de entrada

1. `00_INDICE_DOCUMENTACION.md` — índice autoritativo.
2. `01_PROBLEMA_Y_FINALIDAD.md` — propósito y alcance.
3. `02_ARQUITECTURA.md` — arquitectura general.
4. `06_MODELO_DATOS.md` — modelo de datos.
5. `07_INSTALACION_DEBIAN.md` — instalación productiva.
6. `08_PLAN_PRUEBAS_Y_GATES.md` — estrategia de validación.

Los documentos numerados posteriores conservan la evolución, decisiones,
requisitos y relevos del mismo producto. No deben crearse documentos sueltos
en la raíz salvo README, CHANGELOG, SECURITY, NOTICE o archivos operativos
del repositorio.

Los reportes de ejecución, auditoría y pruebas se guardan en `../reports/`.
